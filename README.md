# Xclean - Cleaning Services HTML5 & CSS3 Website

A pixel-perfect, responsive static recreation of the **[Xclean Demo 1](https://xclean-demo.pbminfotech.com/demo1/)** WordPress theme using clean HTML5, CSS3, vanilla JavaScript, and downloaded authentic media assets.

---

## 🚀 Features

- **Semantic HTML5 & Modern CSS3**: Zero WordPress/Elementor bloat, ultra-fast load times.
- **Offline Authentic Assets**: All 44+ authentic images, SVGs, slide backgrounds, service pictures, and client logos downloaded and stored locally in `assets/images/`.
- **Interactive Hero Carousel**: Auto-playing slide transitions with custom navigation controls, caption animations, and pause-on-hover.
- **Sticky Header**: Responsive header that smoothly elevates and attaches to the top on scroll.
- **Mobile Drawer Menu**: Slide-out navigation drawer with smooth transitions and backdrop blur for phones and tablets.
- **Live Animated Counters**: Achievement statistics dynamically counting up on viewport entry.
- **9 Core Services Showcase**: Responsive card grid with hover zoom effects, tags, and call-to-actions.
- **Client Testimonials & Partners**: Authentic customer reviews with portraits and brand partner strip.
- **4-Column Footer & Newsletter**: Email subscription input with interactive feedback, working hours schedule, quick links, and contact lines.
- **Back to Top Button**: Floating quick-scroll-to-top button.

## 💻 How to View the Website

### Option 1: Direct File Open
Simply double-click `index.html` or open it in any web browser:
```bash
start index.html
```

### Option 2: Run Local Server (Recommended)
Run the included Node.js server:
```bash
node server.js
```
Then visit **[http://localhost:3000](http://localhost:3000)** in your browser.
